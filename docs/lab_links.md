# Lab Links

Gli standard del Lab sono centralizzati e non vengono duplicati in questo repo.

## Hub del Lab

- [dataciviclab](https://github.com/dataciviclab/dataciviclab): hub pubblico,
  mappa repo, catalogo dataset, governance e community.

## Policy organizzative

- [.github](https://github.com/dataciviclab/.github): policy condivise, issue
  template, PR template, componenti CI/CD, ADR.

## Motore tecnico

- [toolkit](https://github.com/dataciviclab/toolkit): CLI, contratti
  RAW → CLEAN → MART, validazioni.
- [lab-connectors](https://github.com/dataciviclab/lab-connectors): HTTP,
  DuckDB, GCS, testing.

## Incubazione e fonti

- [dataset-incubator](https://github.com/dataciviclab/dataset-incubator):
  candidate, support dataset, SBS, pipeline di incubazione.
- [source-observatory](https://github.com/dataciviclab/source-observatory):
  scouting fonti, radar, inventory, source-check.
- [data-explorer](https://github.com/dataciviclab/data-explorer): layer pubblico
  dataset-first.

## Questo repo

- [filiere-agroalimentari](https://github.com/dataciviclab/filiere-agroalimentari):
